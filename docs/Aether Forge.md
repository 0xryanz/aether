# 产品文档：Aether Forge（以太熔炉）

**版本**：v1.0  
**日期**：2026年10月23日  
**状态**：概念设计阶段  

---

## 1. 项目概述

### 1.1 一句话介绍
Aether Forge 是一个基于币安 Agent ID 的 NFT 挖矿项目。用户通过铸造 Relics、合成 Loom 获得挖矿权重，持有即可持续产出代币 $AETHER，并可通过邀请裂变和限时加速获得额外收益。

### 1.2 核心定位
- **AI身份驱动**：必须使用币安 Agent ID（.ai）铸造
- **持有即挖矿**：Loom 作为矿机，被动产出
- **高传播设计**：邀请分成 + 收益排行榜 + 限时加速
- **公平与可持续**：铸造资金 80% 注入流动性，明确排放计划

### 1.3 目标用户
- 币安生态用户（已有或愿意注册 Agent ID）
- 喜欢低操作、高预期收益的链上玩家
- 愿意拉人、晒收益的社区活跃用户
- 小资金参与者（通过二级市场购买）

### 1.4 成功指标（上线后 30 天）
- 公开铸造售罄率 ≥ 90%
- 平均每 Agent ID 邀请 ≥ 1.5 人
- 日活钱包数 ≥ 铸造用户的 40%
- 二级市场日交易额 ≥ 铸造总金额的 15%
- 社交媒体相关讨论量显著增长

## 2. 核心玩法

### 2.1 资产层级

| 资产 | 说明 | 获取方式 | 作用 |
|------|------|----------|------|
| **Relic** | 基础NFT | 铸造 / 二级市场购买 | 合成材料 |
| **Loom** | 挖矿机器 | 燃烧 10 个 Relic 合成 / 二级市场购买 | 持有即挖矿，按权重分配 $AETHER |
| **$AETHER** | 项目代币 | Loom 挖矿产出 | 交易、治理、后续生态使用 |

### 2.2 铸造机制（Relic）
- **总供应量**：100,000 个 Relic
  - 公开铸造：95,000 个
  - 团队预留：5,000 个（教程、奖励、活动）
- **铸造门槛**：必须使用已注册的币安 Agent ID（.ai）
- **每 Agent ID 上限**：最多铸造 4 个 Relic
- **价格**（参考 Ptah，可调整）：
  - 第1个：1 USDT
  - 第2-4个：各 4.5 USDT
  - 满4个总成本约 14.5 USDT
- **支付方式**：USDT 或 BNB（BNB Chain）
- **资金分配**：
  - 80% 注入 $AETHER 流动性池
  - 20% 团队运营

铸造期间流动性持续注入，无需等待售罄。

### 2.3 合成机制（Loom）
- 收集 **10 个 Relic**，在官网一键燃烧合成 **1 个 Loom**
- 合成随时可用，无需等待铸造结束
- Loom 可转让、可交易
- 每个 Loom 初始权重 = 1

### 2.4 挖矿机制（核心）
- **持有即挖矿**：Loom 放在钱包即可，无需质押、无需每日点击
- **权重跟随持有者**：转让 Loom 时，挖矿权重同步转移
- **排放计划**（链上配置，可调整）：
  - 总挖矿储备：建议占代币总量的 40-50%
  - 分阶段排放（示例：7个阶段，共约 21-30 天）
  - 前期权重较高，后期逐步降低
- **领取**：用户随时在官网或合约调用 claim() 领取已产出的 $AETHER

### 2.5 传播与赚钱增强机制（重点）

#### A. 新 Loom 限时加速
- 新合成的 Loom 前 **5 天** 挖矿权重 **×2**
- 第6-10天权重 **×1.5**
- 之后恢复正常权重 1
- 目的：制造“现在合成最划算”的紧迫感，刺激快速合成和传播

#### B. 邀请裂变分成
- 每个 Agent ID 拥有专属邀请链接/码
- 被邀请人铸造或合成时，邀请人永久获得对方 Loom 挖矿收益的 **8%**
- 邀请收益实时显示，可单独 claim
- 前 3 个有效邀请额外奖励 1 个免费 Relic（从团队份额出）

#### C. 公开收益排行榜
- 官网首页实时显示：
  - 全网 Loom 权重排行榜（Top 100）
  - 今日/本周最高收益用户
  - 个人收益对比全网平均
- 支持一键生成“我的挖矿收益海报”并分享到 X / Telegram

## 3. 代币经济模型（$AETHER）

### 3.1 代币基本信息
- 名称：Aether
- 符号：$AETHER
- 链：BNB Chain
- 总供应量：建议 1,000,000,000（可调整）

### 3.2 分配建议（示例）
| 用途 | 比例 | 说明 |
|------|------|------|
| 挖矿储备 | 45% | Loom 持有者挖矿产出 |
| 流动性 | 20% | 铸造资金 80% 注入 + 初始流动性 |
| 团队与顾问 | 15% | 锁仓 12 个月，线性释放 |
| 生态与营销 | 10% | 活动、空投、合作 |
| 国库 | 10% | 长期发展与治理 |

### 3.3 交易与流动性
- 铸造资金持续注入流动性池（PancakeSwap 或项目自建池）
- 挖矿启动后，$AETHER 正式开放交易
- 官方将公布合约地址与交易入口

## 4. 用户流程

### 4.1 新用户路径
1. 注册/登录币安账号 → 创建 Agentic Wallet → 领取 Agent ID
2. 进入官网，使用 Agent ID 铸造 Relic（最多4个）
3. 不足10个时，去二级市场购买 Relic
4. 合成 Loom
5. 持有挖矿，随时 claim $AETHER
6. 分享邀请链接，获取分成收益

### 4.2 老用户/二级市场路径
1. 直接在仅买单市场购买 Relic 或 Loom
2. 合成或持有挖矿
3. 参与邀请与排行榜

### 4.3 市场设计
- 采用**仅买单订单簿**模式（参考 Ptah）
- 买家挂 USDT 买单并锁定资金
- 卖家选择接受哪个买单
- 成交收取 1% 手续费

## 6. 防刷与风控

- 每 Agent ID 铸造上限严格限制
- 邀请有效性验证（被邀请人必须完成至少1次铸造或合成）
- 异常高频交易监控
- 合约权限最小化，团队多签
- 挖矿开始时间由链上参数控制，避免人为操控争议
